## 问答题

1. 介绍一些在c++中你常用的STL容器
 - vector容器，可以频繁写入数据，也可以存储数组数据规避原生数组的冲突错误
2. 你对c++新标准有哪些了解，有哪些实用的特性，简要介绍一下
 - 诸如constexpr等编译期常量，可以处理一些编译期if分支
3. 为什么c++需要预先编译而不能像python一样直接运行，从源文件到可执行文件编译工具链做了哪些操作
 - 预先编译可以让代码在硬件运行时更加高效，源文件经过编译链先进行预处理（链接头文件代码、去除注释），随后再初步编译成汇编代码，接着编译为.o二进制文件，最后链接在一起成为可执行文件
4. 在linux中为什么要用sudo，为什么不全程使用root账户
 - 可以在终端临时提供管理员权限用于处理系统高级操作，该有限的提权也可规避一些误操作
5. 在RM中算法组主要做什么工作，新赛季中有哪些规则变动属于算法组的工作 
 - 在准备期：编写算法、调试算法、将算法批量部署至机甲 在赛期：持续评估机甲的状态、处理异常状况
 - 新赛季规则当中空中机器人的雷达反制机制、雷达解析机制的改动属于算法组工作范围
6. 请你总结一下这段时间的学习经历及经验，以及后续对RM比赛的计划
 - 学习经历：进一步了解了容器的初步用法、了解了cmake的工作机制以及基本用法、初步学习了DFS及A*寻路算法、初步了解相关调度算法
 - 后续计划：在算法组梯队中继续精进算法学习，了解无人机的基本构造，学习无人机相关算法。为明年赛季的无人机出场打下基础
